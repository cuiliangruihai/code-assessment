# 发票数据提取考核

本仓库用于实现发票数据提取程序。程序读取考核任务提供的发票文件，识别指定信息，并按任务要求输出结构化结果。参与者通过 Pull Request（PR）提交代码，评审意见和修改记录保留在 PR 中。

## 任务要求

具体任务说明会明确：

- 支持的发票文件类型和输入方式
- 需要提取的字段及输出格式
- 运行环境、依赖和验收方式

请以任务说明为准。本仓库不规定统一的代码目录，提交者可按实现需要组织文件，并在 PR 中说明项目结构、入口文件和运行方式。

## 提交流程

本仓库公开，任何人都可以 Fork 并提交 PR，无需申请协作者权限。

1. Fork 本仓库，并从 `main` 创建个人分支，建议命名为 `submission/<GitHub用户名>`。
2. 完成实现，并按任务要求提交代码和必要文档。
3. 将分支推送到你的 Fork，创建一个指向本仓库 `main` 的 PR。
4. PR 标题写明提交者，例如：`发票数据提取考核：GitHub用户名`。

PR 描述请说明：

- 支持的输入类型和提取字段
- 安装与运行方法
- 示例输入和输出
- 采用的假设及已知限制

## 评审与合并

评审者会在 PR 中留言或要求修改。收到反馈后，请继续向同一个分支推送更新。仓库维护者负责将通过评审的 PR 合并到 `main`。

## 提交注意事项

- 遵循考核任务中的字段、格式和目录要求。
- 只使用任务提供或经授权的样例发票。不要提交真实业务发票、个人信息、密码、访问令牌或私钥。
