# 考核代码仓库

本仓库用于提交代码考核任务。请通过 Pull Request（PR）提交代码，任务说明、评审意见和修改记录都保留在 PR 中。

## 提交流程

1. 先联系仓库管理员，将你的 GitHub 账号加入私有仓库的协作者。
2. 按任务要求从 `main` 创建个人分支，建议命名为 `submission/<GitHub用户名>/<任务名>`。
3. 按任务说明提交代码和必要的文档。不同任务请分别提交，避免把多个任务放进同一个 PR。
4. 将分支推送到 GitHub，并创建一个指向 `main` 的 PR。
5. PR 标题写明任务和提交者，例如：`考核提交：任务名称 - GitHub用户名`。

PR 描述请简要说明：

- 对应的考核任务
- 完成了哪些内容
- 如何运行或检查代码
- 需要评审者留意的事项

## 评审与合并

评审者会在 PR 中留言或要求修改。收到反馈后，请继续向同一个分支推送更新。仓库管理员负责将通过评审的 PR 合并到 `main`。

## 提交注意事项

- 遵循具体考核任务中的要求和目录约定。
- 不要提交密码、访问令牌、私钥或其他凭据。
- 如果任务没有规定文件布局，请在 PR 描述中说明你的组织方式。
