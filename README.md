# 发票数据提取考核

本仓库用于实现发票数据提取程序。程序读取考核任务提供的发票文件，识别指定信息，并按任务要求输出结构化结果。参与者通过 Pull Request（PR）提交代码，评审意见和修改记录保留在 PR 中。

## 任务要求

具体任务说明会明确：

- 支持的发票文件类型和输入方式
- 需要提取的字段及输出格式
- 运行环境、依赖和验收方式

请以任务说明为准。若任务没有规定代码目录，可将实现放在 `submissions/<GitHub用户名>/` 下。

## 提交流程

1. 联系仓库管理员，将你的 GitHub 账号加入私有仓库的协作者。
2. 从 `main` 创建个人分支，建议命名为 `submission/<GitHub用户名>`。
3. 完成实现，并按任务要求提交代码和必要文档。
4. 将分支推送到 GitHub，创建一个指向 `main` 的 PR。
5. PR 标题写明提交者，例如：`发票数据提取考核：GitHub用户名`。

PR 描述请说明：

- 支持的输入类型和提取字段
- 安装与运行方法
- 示例输入和输出
- 采用的假设及已知限制

## 评审与合并

评审者会在 PR 中留言或要求修改。收到反馈后，请继续向同一个分支推送更新。仓库管理员负责将通过评审的 PR 合并到 `main`。

## 提交注意事项

- 遵循考核任务中的字段、格式和目录要求。
- 只使用任务提供或经授权的样例发票。不要提交真实业务发票、个人信息、密码、访问令牌或私钥。
- 如果任务没有规定文件布局，请在 PR 描述中说明你的组织方式。
